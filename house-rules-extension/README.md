# House Rules for Replit — Chrome Extension

## Install instructions

1. Download or clone this repository and locate the `house-rules-extension` folder.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked** and select the `house-rules-extension` folder.
5. The extension is now installed. Open any page on [replit.com](https://replit.com) and you will see an orange **House Rules** button (🏠) fixed in the bottom-right corner of the page. Click it to toggle the panel open and closed.

To update the extension after making changes to the files, return to `chrome://extensions` and click the refresh icon on the extension card.
